# मॉड्यूल ५: कर्ज आणि क्रेडिट (धोक्याचे क्षेत्र)

मॉड्यूल ५: कर्ज आणि क्रेडिट (धोक्याचे क्षेत्र)

५.१ चांगले कर्ज विरूद्ध वाईट कर्ज — फरक समजून घ्या

सर्वच कर्जे वाईट नसतात. काही कर्जे तुम्हाला पुढे नेतात, तर काही तुम्हाला मागे खेचतात. साधा नियम: "जर कर्जामुळे मालमत्ता (asset) तयार होत असेल = चांगले कर्ज, जर तो उपभोग (consumption) असेल = वाईट कर्ज." मालमत्ता म्हणजे अशी गोष्ट ज्याचे मूल्य वाढते किंवा ज्यातून उत्पन्न मिळते. उपभोग म्हणजे अशी गोष्ट जी मूल्याशिवाय वापरली/संपवली जाते.

स्पष्टीकरणासह १० चांगल्या कर्जांची उदाहरणे:
शिक्षण कर्ज (Education Loan) → कौशल्ये + कमाईची क्षमता वाढते. ₹५ लाखांचे कर्ज घेतले, ₹८ लाख/वर्ष पगाराची नोकरी मिळाली. ROI = ६०% (वार्षिक गुंतवणुकीवरील परतावा). चांगले कर्ज.
गृहकर्ज (Home Loan) → मालमत्तेचे मूल्य वाढते. ₹५० लाखांचा फ्लॅट, १० वर्षांनंतर ₹८० लाखांचा होतो. शिवाय भाड्याचे उत्पन्न शक्य. मालमत्ता निर्मिती.
व्यवसाय कर्ज (Business Loan) → उत्पन्न मिळवून देईल. ₹२ लाखांचे कर्ज, व्यावसायिक नफा ₹५०,०००/महिना. ४ महिन्यांत वसुली.
वैद्यकीय कर्ज (खरे आणीबाणीचे कर्ज) → आरोग्य हीच संपत्ती. जीव वाचवणे. हे कर्ज घेतल्याबद्दल पश्चात्ताप होणार नाही.
कौशल्य विकास कर्ज (Skill Development Loan) → कमाईची क्षमता वाढेल. कोडिंग बूटकॅम्प ₹१ लाख, पगार ₹६ लाखांवरून ₹१२ लाखांवर गेला. २ महिन्यांत वसुली.
शेती कर्ज (Agricultural Loan) → पीक = उत्पन्न. शेतकऱ्यासाठी जगण्याचे आणि वाढीचे साधन.
सोलर पॅनेल कर्ज (Solar Panel Loan) → वीज बिलात बचत. ₹१ लाखाचे कर्ज, मासिक बिल ₹३,००० वरून ₹५०० वर आले. ३ वर्षांत वसुली.
वाहनासाठी कर्ज (उत्पनासाठी) → डिलिव्हरी/व्यावसायिक वापर. बाईक ₹८०,०००, स्विगीकडून ₹१५,०००/महिना. ६ महिन्यांत वसुली.
FD वर कर्ज (Loan against FD) → कमी व्याज (FD दर + १-२%), सुरक्षित. आणीबाणीच्या वेळी FD मोडण्यापेक्षा चांगले.
विद्यार्थी लॅपटॉप कर्ज (Student Laptop Loan) → अभ्यासाचे साधन = भविष्यातील उत्पन्न. कोडिंग/डिजाइन करिअरसाठी आवश्यक. ₹४०,००० चा लॅपटॉप, इंटर्नशिप ₹१५,०००/महिना.

स्पष्टीकरणासह १० वाईट कर्जांची उदाहरणे:
क्रेडिट कार्डवर शॉपिंग → मूल्य संपले, उच्च व्याज. ₹१०,००० चे कपडे, १ वर्षानंतर मूल्य ₹३,०००. व्याज ३६% = एकूण ₹१३,६००. नुकसान = ₹१०,६००.
EMI वर फोन → जलद अवमूल्यन (depreciation). ₹१५,००० चा फोन, १ वर्षानंतर मूल्य ₹८,०००. EMI खर्च ₹१७,०००+. नुकसान निश्चित.
लग्नासाठी वैयक्तिक कर्ज (Personal Loan for Wedding) → उपभोग, कोणतीही मालमत्ता नाही. ₹३ लाखांचे कर्ज, १ दिवसाची पार्टी, ३ वर्षे EMI. कोणताही परतावा नाही.
पेडे लोन (Payday Loan) → ३६-६०% चे शोषक दर. ₹५,००० चे कर्ज, १ महिन्यानंतर ₹६,५००. चक्रावून टाकणारा सापळा.
EMI वर ब्रँडेड कपडे → शून्य उरलेले मूल्य. ₹५,००० चे जॅकेट, ६ महिन्यांनंतर मूल्य ₹५००. EMI = एकूण ₹६,०००.
सुट्टीसाठी कर्ज (Loan for Vacation) → आठवणी, मालमत्ता नाही. ₹५०,००० ची ट्रिप, २ वर्षे EMI. फोटो उरले, कर्जही उरले.
कर्ज काढून क्रिप्टो गुंतवणूक → दुहेरी धोका. कर्ज १२% + क्रिप्टो -५०% = निश्चित आपत्ती.
जुगाराचे कर्ज (Gambling Debt) → सर्वात वाईट प्रकार. कोणतीही मालमत्ता नाही, कोणतेही कौशल्य नाही, निव्वळ तोटा. व्यसन + कर्ज = आयुष्य उद्ध्वस्त.
कार EMI (लक्झरी, गरज नसताना) → अवमूल्यन + व्याज. ₹१० लाखांची कार, ३ वर्षांनंतर मूल्य ₹५ लाख. EMI + देखभाल = ₹१५,०००/महिना. स्टेटस सिम्बॉलची किंमत.
मित्राच्या आणीबाणीसाठी वैयक्तिक कर्ज → तुमचा धोका, त्यांचा फायदा. जर मित्राने थकबाकी केली = तुमचा CIBIL खराब झाला. कधीही करू नका.

सीमावर्ती प्रकरणे — बारकावे:
गृहकर्ज नेहमीच चांगले असते का? नाही! जर EMI उत्पन्नाच्या ६०% असेल, तर ताण = वाईट. जर लोकेशनमध्ये व्हॅल्यू वाढली नाही, तर मध्यम. जेव्हा ते परवडणारे असते तेव्हाच ते चांगले असते.
शिक्षण कर्ज नेहमीच चांगले असते का? नाही! जर कोर्स निरुपयोगी असेल (बोगस युनिव्हर्सिटी), प्लेसमेंट ०%, तर ₹५ लाखांचे कर्ज = वाईट कर्ज. आधी ROI तपासा.

५.२ क्रेडिट कार्ड — संपूर्ण मार्गदर्शक

क्रेडिट कार्ड हे एक साधन आहे — योग्य हातात उपयुक्त, चुकीच्या हातात विनाशकारी. हे कसे कार्य करते: बँक तुम्हाला क्रेडिट लिमिट देते (उदा. ₹५०,०००). तुम्ही खरेदी करता — बँक आधी पैसे देते. बिलिंग सायकलच्या शेवटी, बिल येते. देय तारखेपर्यंत (due date) पूर्ण पेमेंट = शून्य व्याज. किमान पेमेंट (minimum payment) = ३६-४८% APR व्याज आकारले जाते!

बिलिंग सायकल स्पष्टीकरण:
स्टेटमेंट तारीख (Statement Date): दरमहा निश्चित तारीख (उदा. ५ तारीख). यापूर्वीचे व्यवहार या बिलात येतात.
देय तारीख (Due Date): स्टेटमेंट तारखेनंतर १५-२० दिवस (उदा. २५ तारीख). ही पेमेंटची शेवटची तारीख आहे.
ग्रेस पिरियड (Grace Period): खरेदीची तारीख ते देय तारीख = ४५-५० दिवस व्याजमुक्त. पूर्ण भरणा करा = शून्य व्याज.

मिनिमम पेमेंट ट्रॅप — तपशीलवार गणना:
बिल ₹१०,००० आहे. किमान पेमेंट = ₹५०० (५%). तुम्ही फक्त ₹५०० भरले. उर्वरित ₹९,५०० वर, दरमहा ३.५% दराने व्याज = ₹३३२. त्यामुळे पुढच्या महिन्याचे बिल = ₹९,५०० + ₹३३२ + नवीन खरेदी = ₹९,८३२ + नवीन खरेदी. जर तुम्ही फक्त किमान रक्कम भरत राहिलात, तर ₹१०,००० चे बिल भरण्यासाठी साधारण ८ वर्षे लागतील आणि एकूण भरलेली रक्कम = ₹२५,०००-₹२६,००० असेल! ७०%+ अतिरिक्त!

एकूण खर्चासह ५ वास्तविक प्रसंग:
₹१०,००० वर केवळ किमान पेमेंट: महिना १: ₹५०० भरले, ₹९,५०० + ₹३३२ व्याज = ₹९,८३२. महिना २: ₹४९२ किमान, ₹९,३४० + ₹३२७ = ₹९,६६७... ९७ महिन्यांनंतर एकूण भरलेले = ₹२५,९२९. फरक = ₹१५,९२९ अतिरिक्त!
₹५,००० वर ३ महिन्यांचे रिव्हॉल्व्हिंग: महिना १: ₹५,०००. किमान ₹२५०, शिल्लक ₹४,७५० + ₹१६६ = ₹४,९१६. महिना २: किमान ₹२४६, शिल्लक ₹४,६७० + ₹१६३ = ₹४,८३३. महिना ३: किमान ₹२४२, शिल्लक ₹४,५९१ + ₹१६१ = ₹४,७५२. ३ महिन्यांत एकूण भरलेले = ₹७३८ + अजूनही ₹४,७५२ देणे बाकी. हा एक फिरता सापळा (revolving door) आहे.
₹२०,००० वर किमान विरूद्ध पूर्ण पेमेंट: पूर्ण पेमेंट = ₹२०,०००. १२ महिन्यांसाठी किमान पेमेंट = ₹१०,९५४ भरले, ₹१६,३३० अजूनही बाकी. पूर्ण करण्यासाठी एकूण खर्च = ₹४०,०००+.
क्रेडिट कार्डवरून रोख रक्कम काढणे: ₹५,००० काढले. इन्स्टंट चार्जेस: २.५% कॅश ॲडव्हान्स फी = ₹१२५. पहिल्या दिवसापासून ३.५% दराने व्याज = ₹१७५/महिना. १ महिन्यात एकूण = ₹५,३००. कोणताही ग्रेस पिरियड नाही! हे कधीही करू नका.
आंतरराष्ट्रीय व्यवहार: ₹१०,००० ची खरेदी. करन्सी कन्व्हर्जन मार्कअप ३.५% = ₹३५०. मार्कअपवर १८% GST = ₹६३. एकूण अतिरिक्त = ₹४१३. शिवाय परकीय चलनातील (forex) चढ-उताराचा धोका.

रिवॉर्ड पॉइंट्सचे सत्य:
दर ₹१०० खर्चावर वास्तविक मूल्य ₹०.२५-₹०.५०. ₹१०,००० खर्चावर = ₹२५-₹५० मूल्याचे रिवॉर्ड्स. परंतु रिवॉर्ड्ससाठी जास्त खर्च करू नका. ₹१०० कॅशबॅकसाठी ₹५,००० खर्च करणे = ₹४,९०० चे नुकसान. रिवॉर्ड्स हा मार्केटिंगचा सापळा आहे.

विद्यार्थ्यांना क्रेडिट कार्डची गरज आहे की नाही — प्रामाणिक उत्तर:
गरज आहे जर: (१) पूर्ण पेमेंटची शिस्त असेल, (२) CIBIL तयार करायचा असेल, (३) आणीबाणीच्या मदतीची गरज असेल. गरज नाही जर: (१) तुम्ही विचार न करता खर्च करणारे असाल, (२) उत्पन्न अनिश्चित असेल, (३) "मोफत पैसे" समजून वापरणार असाल. शिफारस: विद्यार्थ्यांनी FD वर सिक्युअर्ड क्रेडिट कार्ड घ्यावे (₹१०,०००-₹२०,००० FD). कमी मर्यादा, कमी धोका, CIBIL तयार होते.

सुरक्षित क्रेडिट कार्ड वापरासाठी ७ सुवर्ण नियम:
नेहमी बिल पूर्ण भरा — कधीही किमान भरू नका.
क्रेडिट मर्यादेच्या ३०% पेक्षा जास्त वापरू नका (क्रेडिट स्कोरसाठी). ₹५०,००० मर्यादा = कमाल ₹१५,००० वापर.
देय तारीख लक्षात ठेवा — उशिरा पेमेंट शुल्क + व्याज + क्रेडिट स्कोर घसरण.
पूर्ण पेमेंटसाठी ऑटो-डेबिट सेट करा.
वार्षिक शुल्क असलेली कार्डे घेऊ नका — कमी शुल्काची कार्डे उपलब्ध आहेत (SBI SimplyCLICK ₹४९९/वर्ष जे ₹१ लाखांच्या खर्चावर माफ होते, ICICI Platinum).
क्रेडिट कार्डवरून रोख रक्कम काढू नका — त्वरित व्याज लागू होते, कोणताही ग्रेस पिरियड नाही.
रिवॉर्ड पॉइंट्ससाठी जास्त खर्च करू नका — ₹१०० कॅशबॅकसाठी ₹५,००० खर्च करणे = तोटा.

५.३ EMI — संपूर्ण चित्र

EMI = Equated Monthly Installment (समान मासिक हप्ता). तुम्ही एखादी गोष्ट विकत घेता आणि दरमहा पैसे देता. ऐकायला सोपे वाटते, पण यात लपलेले खर्च असतात.

नो-कॉस्ट EMI चे वास्तव:
"नो-कॉस्ट" EMI मध्ये प्रोसेसिंग फी (₹१९९-₹९९९), GST असतो आणि काहीवेळा EMI वर प्रॉडक्टची किंमत अपफ्रंट खरेदीपेक्षा जास्त असते. उदाहरण: १२ महिन्यांच्या "नो-कॉस्ट EMI" वर ₹१५,००० चा फोन — प्रोसेसिंग फी ₹३०० + GST ₹५४ = एकूण ₹१५,३५४. हे मोफत नाही!

EMI सुरक्षित मर्यादा: एकूण EMI ≤ मासिक उत्पन्नाच्या ३०%. जर उत्पन्न ₹१५,००० असेल तर कमाल EMI = ₹४,५००. यापेक्षा जास्त EMI = धोकादायक क्षेत्र. एकाच वेळी अनेक EMI घेऊ नका — एक संपवा मग दुसरा घ्या.

EMI कॅल्क्युलेटर सूत्र:
EMI = [P × R × (1+R)^N] / [(1+R)^N - 1]
जिथे P = मुद्दल (Principal), R = मासिक व्याजदर, N = महिन्यांची संख्या.
उदाहरण: ₹५०,००० चा लॅपटॉप, १८ महिने, वार्षिक १४%.
R = 14%/12 = 1.167% = 0.01167
EMI = [50,000 × 0.01166 × (1.01166)^18] / [(1.01166)^18 - 1] = ₹३,०९६/महिना

डाऊन पेमेंट आणि फोरक्लोजर:
डाऊन पेमेंट (Down Payment): EMI वरसुद्धा १०-२०% डाऊन पेमेंट द्यावे लागते. कमी डाऊन पेमेंट = जास्त EMI.
फोरक्लोजर चार्जेस (Foreclosure Charges): EMI मुदतीपूर्वी बंद करत आहात? २-५% दंड लागू होतो. अटी व शर्ती (fine print) बारकाईने वाचा.

(टीप: भारतात CIBIL ला अधिकृत वापरकर्त्याचे रिपोर्टिंग सुसंगत नाही — सध्या प्रामुख्याने Amex सप्लिमेंटरी कार्डे रिपोर्ट करतात. इतर बँका रिपोर्टिंग सुरू करत आहेत परंतु पडताळणी करा.)

५ सामान्य CIBIL गैरसमज दूर:
"CIBIL तपासल्याने स्कोर खराब होतो" — सॉफ्ट इन्क्वायरी (स्वतः तपासणे) चा काहीही परिणाम होत नाही. हार्ड इन्क्वायरी (बँकेने तपासणे) चा थोडा परिणाम होतो.
"कर्ज नाही = चांगला CIBIL" — नाही! कोणताही क्रेडिट इतिहास नाही = कोणताही CIBIL स्कोर नाही. "स्कोर नसणे" ही देखील एक समस्या आहे.
"एकदा स्कोर वाढला की तो फिक्स होतो" — नाही! तो दरमहा अपडेट होतो. थकबाकी = त्वरित घसरण.
"CIBIL फक्त कर्जासाठी आहे" — नाही! भाडेतत्त्वावर घर, नोकरी, इन्शुरन्स प्रीमियम या सर्वांवर परिणाम होतो.
"CIBIL सुधारण्यासाठी ५ वर्षे लागतात" — नाही! ६-१२ महिन्यांत लक्षणीय सुधारणा शक्य आहे.

५.८ कर्जातून बाहेर कसे पडावे — ६ सिद्ध धोरणे

१. ॲव्हलांच पद्धत (Avalanche Method) — गणितीयदृष्ट्या सर्वोत्तम:
सर्वप्रथम उच्च व्याजदर असलेले कर्ज फेडा. एकूण व्याज सर्वात कमी लागते.
उदाहरण: क्रेडिट कार्ड ३६% > वैयक्तिक कर्ज १८% > शिक्षण कर्ज ९%.
धोरण: सर्वांमध्ये किमान रक्कम भरा, क्रेडिट कार्डवर अतिरिक्त ₹२,००० टाका. क्रेडिट कार्ड निरंक झाल्यावर, वैयक्तिक कर्जावर अतिरिक्त ₹२,००० टाका. एकूण ₹५०,००० चे कर्ज २४ महिन्यांत पूर्ण होईल विरूद्ध ४८ महिने (किमान पेमेंट पद्धत).

२. स्नोबॉल पद्धत (Snowball Method) — मानसिकदृष्ट्या सर्वोत्तम:
सर्वप्रथम सर्वात लहान रकमेचे कर्ज फेडा. जलद यशामुळे प्रेरणा मिळते.
उदाहरण: ₹५,००० क्रेडिट कार्ड १ > ₹८,००० क्रेडिट कार्ड २ > ₹२०,००० वैयक्तिक कर्ज > ₹५०,००० शिक्षण कर्ज.
धोरण: आधी ₹५,००० चे कर्ज फेडा (१ महिना). सेलिब्रेशन! मग ₹८,००० चे कर्ज (२ महिने). वेग वाढत जातो.

३. बॅलन्स ट्रान्सफर (Balance Transfer):
कमी व्याजाच्या कार्डवर शिफ्ट करा. ०% बॅलन्स ट्रान्सफर कार्डे उपलब्ध आहेत (६ महिने). ३६% वरून ०% वर ₹२०,००० शिफ्ट करा = ६ महिन्यांत ₹३,६०० व्याजाची बचत.

४. वाटाघाटी (Negotiation):
बँकेशी बोला, व्याजदर कमी करण्यास सांगा. आर्थिक अडचणींचे कारण सांगा — पुनर्रचना (restructuring) शक्य आहे. ३६% ऐवजी २४% झाले तरी मोठा दिलासा मिळतो.

५. एकत्रीकरण (Consolidation):
सर्व कर्जे कमी व्याजाच्या एका कर्जात एकत्रित करा. १२% दराने वैयक्तिक कर्ज घेऊन ३६% चे क्रेडिट कार्ड कर्ज फेडा. EMI व्यवस्थापन करण्यायोग्य होतो. उदाहरण: सरासरी ३०% दराने एकूण ₹३०,००० कर्ज → १२% वर एकत्रित करा = ₹१५,००० व्याजाची बचत.

नो-कॉस्ट EMI मधील लपलेल्या खर्चाकडे दुर्लक्ष करणे — प्रोसेसिंग फी + GST = मोफत नाही. ₹१५,००० फोन EMI = वास्तविक ₹१५,३५४.

क्रेडिट कार्डवरून रोख रक्कम काढणे — त्वरित व्याज लागू होते, कोणताही ग्रेस पिरियड नाही. ₹५,००० = १ महिन्यात ₹५,३००.

अनेक EMIs घेणे — ३०% उत्पन्न नियमाचे पालन करा, यापेक्षा जास्त EMI = धोकादायक क्षेत्र. EMI 1 + EMI 2 + EMI 3 = मृत्यूचा सापळा.

कर्जाने कर्ज फेडणे — वैयक्तिक कर्ज घेऊन क्रेडिट कार्ड फेडणे = सहसा वाईट निर्णय. तात्पुरता दिलासा, कायमस्वरूपी समस्या.

शिक्षण कर्जाला "चांगले कर्ज" मानून जास्त कर्ज घेणे — टियर-३ कॉलेजसाठी ₹२० लाखांचे कर्ज = वाईट निर्णय. आधी ROI तपासा.

CIBIL कडे दुर्लक्ष करणे — "मला आता कर्जाची गरज नाही" — भविष्यात लागेल. CIBIL तयार होण्यास वेळ लागतो.

पेडे लोन / ॲप लोन घेणे — ३६-६०% व्याज, शोषक. एकदा घेतले की सापळ्यात अडकले.

महत्त्वाचे मुद्दे (महत्त्वाचे निष्कर्ष) (मॉड्यूल ५)

चांगले कर्ज मालमत्ता तयार करते, वाईट कर्ज उपभोग आहे — फरक समजून घ्या. शिक्षण/घर = चांगले, क्रेडिट कार्ड शॉपिंग = वाईट.

नेहमी क्रेडिट कार्डचे बिल पूर्ण भरा — किमान पेमेंट हा एक सापळा आहे. ३६-४८% APR = संपत्ती नष्ट करणारा.

EMI एकूण उत्पन्नाच्या ३०% पेक्षा जास्त नसावा — यापेक्षा जास्त = धोकादायक क्षेत्र.

७५०+ क्रेडिट स्कोरचे लक्ष्य ठेवा — कर्जाच्या चांगल्या अटी, भाड्याची मंजुरी, नोकरीच्या संधी. सिक्युअर्ड कार्डने सुरुवात करा.

कर्जाच्या सापळ्यात अडकल्यास ॲव्हलांच किंवा स्नोबॉल पद्धत वापरा — थांबू नका, कृती करा. साइड इनकमने वेग वाढवा.

सामान्य गैरसमज (मॉड्यूल ५)

"सर्व कर्जे वाईट असतात" — नाही! शिक्षण कर्ज, गृहकर्ज हे चांगले कर्ज आहे. मालमत्ता निर्मिती + उत्पन्न निर्मिती = चांगले.

"क्रेडिट कार्ड म्हणजे मोफत पैसे" — चुकीचे! उसने घेतलेले पैसे ज्यावर ३६-४८% व्याज लागू होते. मोफत पैसे नाहीत, महागडे पैसे.

"नो-कॉस्ट EMI खरोखर मोफत असतो" — चुकीचे! प्रोसेसिंग फी + GST हे लपलेले खर्च आहेत. EMI वर प्रॉडक्टची किंमतही जास्त असते.

"कर्ज काढून गुंतवणूक करणे हुशारीचे आहे" — सहसा नाही! १२% कर्जावर १२% परतावा = ब्रेक इव्हन, जोखीममुक्त नाही. लिव्हरेज (Leverage) = दुधारी तलवार.

"CIBIL स्कोर तपासल्याने स्कोर खराब होतो" — सॉफ्ट इन्क्वायरीचा काहीही परिणाम होत नाही. स्वतः बिंधास्त तपासा.

## ५.९ विद्यार्थी कर्ज परतफेड धोरणे — हुशारीने कर्जाची परतफेड करा

शिक्षण कर्ज घेतले आहे? आता परतफेडीची वेळ आली आहे. मोरॅटोरियम संपला आहे, नोकरी मिळाली आहे आणि आता EMI भरावा लागेल. पण तुम्ही कसे भरता — यामुळे मोठा फरक पडतो. चुकीच्या धोरणाने तुम्ही ₹१-२ लाख अतिरिक्त व्याज भराल. योग्य धोरणाने तुम्ही २-३ वर्षे आधी कर्जमुक्त व्हाल. येथे आपण ५ सिद्ध परतफेड धोरणे, भारतीय उदाहरणांसह पाहू आणि तुमच्या परिस्थितीनुसार कोणते सर्वोत्तम आहे ते जाणून घेऊ.

### शिक्षण कर्ज परतफेड विहंगावलोकन — मोरॅटोरियम नंतर काय होते?

मोरॅटोरियम कालावधीनंतर (कोर्स + ६-१२ महिने) तुम्हाला EMI भरावा लागतो. बँक तुम्हाला नोकरी शोधण्यासाठी १-२ वर्षांचा वेळ देते, त्यानंतर EMI सुरू होतो. उदाहरण: १० वर्षांसाठी ९.५% दराने ₹८ लाखांचे कर्ज = ₹१०,३५२/महिना EMI. एकूण भरलेले व्याज = ₹४.४२ लाख. म्हणजेच तुम्ही ₹८ लाखांच्या कर्जावर एकूण ₹१२.४२ लाख भराल.

**महत्त्वाचे मुद्दे:**
- मोरॅटोरियम दरम्यान व्याज जमा होते (CSIS शिवाय)
- जेव्हा परतफेड सुरू होते तेव्हा मुद्दल + जमा झालेले व्याज दोन्ही भरावे लागते
- 80E कर सवलत उपलब्ध — भरलेल्या व्याजावर कर वजावट (tax deduction)
- पूर्वपेमेंटचा (prepayment) पर्याय राहतो, परंतु फोरक्लोजर शुल्क तपासा

### ५ परतफेड धोरणे — तपशीलवार तुलना

#### १. आक्रमक परतफेड (Aggressive Repayment) — त्वरित भरणा करा, व्याज वाचवा

**हे कसे कार्य करते:** तुम्ही तुमच्या उत्पन्नातील जास्तीत जास्त रक्कम कर्जासाठी वापरता. किमान EMI पेक्षा जास्त, शक्य तितकी रक्कम. लक्ष्य: २-३ वर्षांत कर्ज फेडणे.

**फायदे:**
- एकूण व्याज सर्वात कमी असते
- कर्ज लवकर संपते — लवकर आर्थिक स्वातंत्र्य
- क्रेडिट स्कोर सुधारतो
- ताण कमी होतो

**तोटे:**
- रोखता (liquidity) कमी होते — आणीबाणीसाठी पैसे वाचणार नाहीत
- गुंतवणुकीच्या संधी मुकू शकतात
- खूप जास्त आक्रमक असल्यास बर्नआउट (मानसिक ताण) होऊ शकतो

**कोणासाठी सर्वोत्तम:** ज्यांचे उत्पन्न स्थिर आहे, आणीबाणीचा निधी (emergency fund) आहे आणि ज्यांना कर्जापासून लवकर स्वातंत्र्य हवे आहे.

**भारतीय उदाहरण:** खाली स्नेहाचे उदाहरण पहा.

#### २. ॲव्हलांच पद्धत (Avalanche Method) — गणितीयदृष्ट्या सर्वोत्तम

**हे कसे कार्य करते:** प्रथम सर्वोच्च व्याजदर असलेला कर्जाचा भाग फेडा. उर्वरित कर्जावर किमान EMI भरा. सर्वोच्च व्याज पूर्ण झाल्यावर, पुढील सर्वोच्च व्याजावर लक्ष केंद्रित करा.

**फायदे:**
- एकूण व्याज कमी करते
- आर्थिकदृष्ट्या इष्टतम (optimal)
- शिस्तबद्ध दृष्टिकोन

**तोटे:**
- त्वरित यश मिळत नाही — सर्वात लहान कर्ज आधी संपत नाही
- मोठे कर्ज मोठे असल्यास प्रेरणा कमी होऊ शकते
- ट्रॅक ठेवण्यासाठी थोडे क्लिष्ट

**कोणासाठी सर्वोत्तम:** आकड्यांवर लक्ष केंद्रित करणारे गणित-सज्ज लोक, आणि ज्यांच्याकडे संयम आहे.

**भारतीय उदाहरण:** खाली राहुलचे उदाहरण पहा.

#### ३. स्नोबॉल पद्धत (Snowball Method) — प्रेरणेसाठी सर्वोत्तम

**हे कसे कार्य करते:** प्रथम सर्वात लहान शिल्लक असलेले कर्ज फेडा. जलद यश प्रेरणा देते. नंतर पुढील सर्वात लहान कर्जाकडे वळा.

**फायदे:**
- जलद यशाने उच्च प्रेरणा मिळते
- मानसिकदृष्ट्या समाधानकारक
- ट्रॅक ठेवण्यास सोपे

**तोटे:**
- एकूण व्याज खर्च जास्त असतो (गणितीयदृष्ट्या कमी इष्टतम)
- सर्वात लहान कर्जावर लक्ष केंद्रित केल्याने मोठ्या कर्जांवरील व्याज वाढते
- भावनिक निर्णय तर्कावर मात करू शकतात

**कोणासाठी सर्वोत्तम:** जे लोक भावनिकदृष्ट्या प्रेरित होतात, ज्यांना जलद निकालांची गरज असते आणि प्रेरणेसाठी लहान यश महत्त्वाचे असते.

**भारतीय उदाहरण:** खाली प्रियाचे उदाहरण पहा.

#### ४. उत्पन्नावर आधारित परतफेड (Income-Driven Repayment) — लवचिकतेसाठी

**हे कसे कार्य करते:** तुमच्या उत्पन्नानुसार EMI निश्चित केला जातो. साधारणपणे मासिक उत्पन्नाच्या १०-१५%. उत्पन्न कमी असल्यास, EMI कमी. उत्पन्न वाढल्यास, EMI वाढतो.

**फायदे:**
- आर्थिक अडचणीच्या काळात दिलासा
- उत्पन्नानुसार EMI समायोज्य (adjustable)
- २०-२५ वर्षांनंतर कर्जमाफी शक्य (काही कार्यक्रमांमध्ये)

**तोटे:**
- एकूण व्याज खर्च जास्त असतो
- कर्जाची मुदत मोठी असते
- दीर्घकालीन कर्जाचा मानसिक भार

**कोणासाठी सर्वोत्तम:** ज्यांचे उत्पन्न अनिश्चित आहे, फ्रीलान्सर्स, उद्योजक किंवा नोकरी गेल्यानंतर.

**भारतीय उदाहरण:** खाली प्रियाचे उदाहरण पहा.

#### ५. रीफायनान्सिंग (Refinancing) — व्याजदर कमी करा

**हे कसे कार्य करते:** विद्यमान कर्ज नवीन बँकेत ट्रान्सफर करा जी कमी व्याजदर देते. याला बॅलन्स ट्रान्सफर म्हणतात. १२% चे ९.५% झाले तरी मोठा फरक पडतो.

**फायदे:**
- व्याजदर कमी होतो
- मासिक EMI कमी होऊ शकतो
- एकूण व्याजात लक्षणीय बचत

**तोटे:**
- प्रोसेसिंग फी लागू होते (कर्जाच्या ०.५-१%)
- कागदपत्रे पुन्हा करावी लागतात
- प्रत्येक बँक पात्र नसते

**कोणासाठी सर्वोत्तम:** ज्यांचा मूळ व्याजदर जास्त आहे आणि नवीन बँकेसाठी पात्र होण्यासाठी क्रेडिट स्कोर चांगला आहे.

**भारतीय उदाहरण:** खाली अमितचे उदाहरण पहा.

### कधी पूर्वपेमेंट (Prepay) करावे विरूद्ध कधी गुंतवणूक करावी — गणितीय तुलना

**निर्णय मॅट्रिक्स:**

**कर्ज पूर्वपेमेंट करा जर:**
- कर्जाचा व्याजदर > अपेक्षित गुंतवणुकीचा परतावा
- कर्जाचा व्याजदर > १०% (वैयक्तिक कर्ज, क्रेडिट कार्ड)
- तुम्ही जोखीम-द्वेषी (risk-averse) असाल (पूर्वपेमेंटद्वारे निश्चित परतावा)
- कर्जामुळे ताण येत असेल

**याऐवजी गुंतवणूक करा जर:**
- कर्जाचा व्याजदर < अपेक्षित गुंतवणुकीचा परतावा
- कर्जाचा व्याजदर < ८% (शिक्षण कर्ज, गृहकर्ज)
- तुम्ही मार्केटच्या जोखमीबाबत कम्फर्टेबल असाल
- तुमची जोखीम सहन करण्याची क्षमता जास्त असेल

**गणितीय उदाहरण:**
कर्ज: ५ वर्षांसाठी ९% दराने ₹५ लाख. किमान EMI = ₹१०,३७९.
पर्याय A: दरमहा ₹५,००० अतिरिक्त पूर्वपेमेंट करा → ३ वर्षांत कर्ज पूर्ण, व्याजाची बचत = ₹३८,३४९.
पर्याय B: १२% परताव्याच्या SIP मध्ये दरमहा ₹५,००० गुंतवा → ३ वर्षांनंतर गुंतवणुकीचे मूल्य = ₹२.१६ लाख. थकीत कर्ज = ₹२.२७ लाख. निव्वळ स्थिती = ₹२.१५L - ₹२.२७L = -₹०.१२L (लहान तोटा). त्यामुळे पूर्वपेमेंट करणे चांगले.

पण जर कर्जाचा दर ७% असेल आणि गुंतवणुकीचा परतावा १२% असेल: निव्वळ नफा = ५% लॅब (arbitrage). १० वर्षांमध्ये लक्षणीय. तथापि, लक्षात ठेवा: गुंतवणुकीचा परतावा निश्चित नसतो, कर्जाचे पूर्वपेमेंट हा निश्चित परतावा असतो.

**साधारण नियम (Rule of Thumb):**
- कर्जाचे व्याज > १०% असल्यास → पूर्वपेमेंट करा
- कर्जाचे व्याज ७-१०% असल्यास → जोखीम क्षमतेवर अवलंबून आहे
- कर्जाचे व्याज < ७% असल्यास → गुंतवणुकीचा विचार करा (पण शांततेसाठी काही पूर्वपेमेंट करा)

### परतफेडीदरम्यान कलम 80E कर सवलत ऑप्टिमायझेशन

**80E म्हणजे काय?**
आयकर कायद्याचे कलम 80E शिक्षण कर्जावर भरलेल्या व्याजावर वजावट (deduction) देते. व्याजाच्या रकमेवर कोणतीही मर्यादा नाही. परतफेड सुरू झाल्यापासून ८ वर्षांसाठी वजावट उपलब्ध आहे.

**ऑप्टिमायझेशन टिप्स:**
१. **दरवर्षी क्लेम करा** — वजावट चुकवू नका. बँकेकडून व्याज प्रमाणपत्रे (interest certificates) घ्या.
२. **लवकर परतफेड सुरू करा** — तुम्ही मोरॅटोरियम दरम्यान परतफेड सुरू केल्यास (ऐच्छिक), तुम्ही 80E आधी क्लेम करू शकता.
३. **संयुक्त कर्ज फायदे** — पालक सह-कर्जदार असल्यास, ते देखील 80E क्लेम करू शकतात.
४. **व्याज घटकाचा मागोवा घ्या** — EMI मध्ये व्याज आणि मुद्दल असते. वजावट फक्त व्याजावर उपलब्ध असते.
५. **कागदपत्रे ठेवा** — कर्ज मंजुरी पत्र, व्याज प्रमाणपत्र, परतफेड वेळापत्रक.

**उदाहरण गणना:**
वार्षिक भरलेले व्याज: ₹६०,०००
टॅक्स ब्रॅकेट: २०%
बचत झालेला कर: ₹६०,००० × २०% = ₹१२,००० प्रतिवर्ष.
८ वर्षांमध्ये: ₹९६,००० बचत.

**टीप:** 80E फक्त व्याजासाठी आहे, मुद्दलासाठी नाही. त्यामुळे तुम्ही पूर्वपेमेंट केले तरीही तुम्हाला व्याजाच्या भागावर वजावट मिळते.

### भारतातील कर्जमाफी कार्यक्रम (Loan Forgiveness Programs)

**सध्याची स्थिती:** भारतात विद्यार्थी कर्जमाफीचे कार्यक्रम मर्यादित आहेत. पण काही आहेत:

१. **CSIS (सेंट्रल सेक्टर इंटरेस्ट सबसिडी)** — पात्र विद्यार्थ्यांसाठी मोरॅटोरियम दरम्यान व्याज सबसिडी. पूर्णपणे माफी नाही, पण भार कमी करते.

२. **राज्य सरकार योजना** — काही राज्ये शेतकऱ्यांची मुले, SC/ST विद्यार्थी किंवा ग्रामीण भागात काम करणाऱ्यांसाठी कर्जमाफी देतात. उदाहरण: बिहारच्या स्टुडंट क्रेडिट कार्ड योजनेत काही माफीच्या तरतुदी आहेत.

३. **पब्लिक सर्व्हिस लोन फॉरगिव्हनेस (काल्पनिक)** — भारतात सध्या असा कोणताही कडक कार्यक्रम नाही, परंतु सरकारी कर्मचाऱ्यांसाठी काही सवलती आहेत.

४. **NPA सेटलमेंट** — कर्ज NPA झाल्यास बँका काही वेळा कमी रकमेत कर्ज सेटल करतात. पण CIBIL वर परिणाम होतो.

**वास्तविक तपासणी:** अमेरिकेप्रमाणे भारतात मोठ्या प्रमाणावर कर्जमाफी नाही. त्यामुळे परतफेडीचे नियोजन अत्यंत महत्त्वाचे आहे.

### ग्रेस पिरियड व्यवस्थापन टिप्स

**ग्रेस पिरियड दरम्यान काय करावे (मोरॅटोरियम + ६-१२ महिने):**

१. **नोकरीचा आक्रमकपणे शोध घ्या** — नोकरीच्या शोधात हा वेळ गुंतवा. प्लेसमेंट सीझनचा पूर्ण फायदा घ्या.

२. **आणीबाणीचा निधी तयार करा** — नोकरी मिळताच आधी ३-६ महिन्यांचा आणीबाणीचा निधी तयार करा. कर्जाची परतफेड सुरू झाल्यावर दबाव कमी असेल.

३. **बजेट तयार करा** — नोकरीच्या पगारातील ५०% कर्जासाठी, ३०% खर्चासाठी, २०% बचत/गुंतवणुकीसाठी आखा.

४. **ऐच्छिक पेमेंट करा** — शक्य असल्यास थोडे पैसे भरा. व्याज कमी जमा होईल. अगदी ₹१,०००/महिना सुद्धा मदत करतो.

५. **80E चा फायदा घ्या** — तुम्ही आधीच परतफेड सुरू केली असल्यास, कर सवलतीचा दावा करा.

६. **कर्ज पुनर्रचना एक्सप्लोर करा** — नोकरी न मिळाल्यास बँकेशी बोला. मुदतवाढ शक्य आहे.

#### केस STUDY ४: अमित — १२% वरून ९.५% वर रीफायनान्स केले

**पार्श्वभूमी:** अमित, इंजिनिअर, त्याने खाजगी बँकेकडून १२% व्याजाने शिक्षण कर्ज घेतले (कारण त्याने पर्यायांचा शोध घेतला नव्हता). २ वर्षांनंतर, त्याच्या लक्षात आले की तो जास्त पैसे देत आहे.

**धोरण:** कमी व्याजदरावर रीफायनान्स.

**त्याने हे कसे केले:**

- SBI कडे अर्ज केला (ज्याने त्याच्या प्रोफाइलसाठी ९.५% ऑफर केली)
- ०.५% प्रोसेसिंग फीसह कर्ज ट्रान्सफर केले
- मूळ कर्ज: १० वर्षांसाठी १२% दराने ₹१० लाख
- नवीन कर्ज: ८ वर्षांसाठी ९.५% दराने ₹९.५ लाख (प्रोसेसिंगनंतर) (कमी मुदत)

**निकाल:**

- एकूण भरलेले व्याज: ₹४.१० लाख (₹७.२२ लाखांऐवजी)
- व्याजाची बचत: ₹३.१२ लाख
- मुदत २ वर्षांनी कमी झाली

**महत्त्वाचा निष्कर्ष:** रीफायनान्सिंगमुळे लाखांची बचत होऊ शकते. काही वर्षांनंतर नेहमी दरांची तुलना करा.

### EMI ऑप्टिमायझेशन धोरणे

१. **ऑटो-डेबिट सेटअप** — EMI कधीही चुकणार नाही. उशिरा शुल्क + क्रेडिट स्कोरवरील परिणामापासून बचाव.

२. **सॅलरी अकाउंट लिंक** — सॅलरी अकाउंटवरून ऑटो-डेबिट = कधीही चुकणार नाही.

३. **पगार वाढीसह EMI वाढवा** — प्रत्येक १०% पगार वाढीवर ५% EMI वाढवा. कर्ज लवकर संपते.

४. **अचानक मिळालेल्या पैशांचा वापर (Windfall Utilization)** — बोनस, टॅक्स रिफंड, भेटवस्तू — ५०% कर्ज पूर्वपेमेंटसाठी.

५. **द्वि-प्ताहिक (Bi-weekly) EMI** — महिन्याऐवजी दर २ आठवड्यांनी EMI भरा. वर्षाला १ अतिरिक्त पेमेंट = मुदत कमी होते.

६. **पेमेंट्स राऊंड अप करा** — ₹१०,४०० EMI असल्यास ₹११,००० भरा. दरमहा ₹६०० अतिरिक्त = वर्षाला ₹७,२०० अतिरिक्त.

७. **लंपसम पूर्वपेमेंट** — वर्षातून एकदा एकरकमी (lump sum) रक्कम भरा. अगदी ₹५०,००० अतिरिक्त दिल्यास व्याज वाचते.

### मानसिक भाराचे व्यवस्थापन

कर्जाची परतफेड ताणतणावाची असते. येथे काही टिप्स आहेत:

१. **विझ्युअलायझेशन (मानसिक चित्र)** — कर्जाची रक्कम लहान तुकड्यांमध्ये टाका. ₹८ लाखांचे कर्ज = ₹१०,००० चे ८० तुकडे. दरमहा एक तुकडा संपवा.

२. **प्रगतीचा मागोवा (Progress Tracking)** — स्प्रेडशीट बनवा, दरमहा शिल्लक रकमेचा मागोवा घ्या. दृश्य प्रगती प्रेरणा देते.

३. **माईलस्टोन रिवॉर्ड्स** — प्रत्येक ₹१ लाख पूर्वपेमेंटवर लहान रिवॉर्ड घ्या (बाहेर जेवण, चित्रपट). पण बजेटमध्ये.

४. **सपोर्ट सिस्टम** — कर्ज फेडलेल्या मित्रांशी बोला. त्यांचा अनुभव उपयुक्त ठरेल.

५. **फायनान्शियल थेरपी** — खूप चिंता असल्यास, आर्थिक सल्लागाराशी (financial counselor) बोला. अनेक ऑनलाईन पर्याय उपलब्ध आहेत.

६. **तुमच्या नियंत्रणात असलेल्या गोष्टींवर लक्ष केंद्रित करा** — तुम्ही व्याजदर नियंत्रित करू शकत नाही, पण अतिरिक्त पेमेंट करू शकता. जे नियंत्रणात आहे त्यावर लक्ष द्या.

७. **लहान यशाचा आनंद साजरा करा** — प्रत्येक महिन्याच्या अतिरिक्त पेमेंटचा आनंद साजरा करा. वेग वाढत जातो.

### इतर मॉड्युल्सचे संदर्भ (Cross-References)

- **मॉड्यूल १० (कर सवलती):** शिक्षण कर्जाशी संबंधित तपशीलवार 80E, 80C आणि इतर कर सवलती पहा. व्याज प्रमाणपत्र कसे घ्यावे, ITR मध्ये दावा कसा करावा.
- **मॉड्यूल १२ (बिहेव्हिअरल फायनान्स):** कर्ज परतफेड मानसशास्त्र, विलंबाने मिळणारे समाधान (delayed gratification), भावनिक खर्च विरूद्ध तर्कसंगत निर्णय. बर्नआउट न होता कर्जाचा ताण कसा व्यवस्थापित करावा ते वाचा.

## ५.१० क्रेडिट बिल्डिंग टाइमलाईन — वयाच्या १८ ते २५ वर्षांपर्यंतचा संपूर्ण रोडमॅप

क्रेडिट स्कोर हे एक अदृश्य रिपोर्ट कार्ड आहे जे तुमचे आर्थिक जीवन ठरवते. तुम्हाला नोकरी मिळते तेव्हा बॅकग्राउंड चेक होतो, तुम्हाला भाड्याचा फ्लॅट हवा असेल तेव्हा CIBIL तपासला जातो, तुम्हाला कर्ज हवे असेल तर स्कोर ७५०+ असावा. पण हा स्कोर असाच तयार होत नाही — वयाच्या १८ ते २५ वर्षांपर्यंत सतत प्रयत्नांची गरज असते. प्रॉडक्ट शिफारशींसह १८ ते २५ वयोगटातील क्रेडिट कसे तयार करावे याबद्दलचा संपूर्ण रोडमॅप येथे आहे.

### लवकर क्रेडिट तयार करणे का महत्त्वाचे आहे

**पहिला नोकरीचा अर्ज:** अनेक कंपन्या (विशेषतः फायनान्स, MNCs) बॅकग्राउंड चेक दरम्यान क्रेडिट स्कोर तपासतात. वाईट स्कोर = नोकरीची ऑफर लांबणीवर पडली किंवा रद्द झाली.

**भाड्याचा अर्ज:** घरमालक चांगला क्रेडिट असलेल्या भाडेकरूंना प्राधान्य देतात. ७५०+ स्कोर = सोपी मंजुरी, कमी सुरक्षा ठेव (security deposit).

**कर्ज पात्रता:** गृहकर्ज, कार कर्ज, वैयक्तिक कर्ज — सर्वांसाठी क्रेडिट स्कोर महत्त्वाचा आहे. लवकर सुरुवात = लांब क्रेडिट इतिहास = चांगला स्कोर.

**विमा प्रीमियम:** काही विमा कंपन्या क्रेडिट स्कोर तपासतात. चांगला स्कोर = कमी प्रीमियम.

**आर्थिक स्वातंत्र्य:** चांगला क्रेडिट तुम्हाला पर्याय देतो. वाईट क्रेडिट तुम्हाला बाहेर ठेवते.

### क्रेडिट बिल्डिंग टाइमलाईन — वर्षागणिक

#### वय १८: पायाभूत टप्पा (Foundation Stage)

**कृती:**
१. **विद्यार्थी क्रेडिट कार्ड** — FD-बॅक्ड कार्ड घ्या. ₹१०,००० FD = ₹८,०००-₹१०,००० मर्यादा. SBI स्टुडंट प्लस, HDFC फॉरेक्स कार्ड.
२. **अधिकृत वापरकर्ता म्हणून जोडा** — पालकांच्या कार्डवर अधिकृत वापरकर्ता बना. त्यांचा क्रेडिट इतिहास तुमचाही बनतो.
३. **तुमच्या नावावर युटिलिटी बिले** — फोन, वायफाय, विजेचे बिल तुमच्या नावावर. सातत्यपूर्ण पेमेंट्स इतिहास तयार करतात.
४. **लहान सुरुवात करा** — ₹५,००० मर्यादेसह प्रारंभ करा. मोठ्या मर्यादेचे आकर्षण नाही.

**प्रॉडक्ट शिफारशी:**
- SBI स्टुडंट प्लस ॲडव्हांटेज कार्ड (FD-बॅक्ड)
- HDFC फॉरेक्स कार्ड (विद्यार्थ्यांसाठी)
- ICICI बँक स्टुडंट क्रेडिट कार्ड

**टाळायच्या चुका:**
- एकाधिक कार्ड अर्ज (क्रेडिट भुकेला टॅग)
- जास्त खर्च करणे (३०% नियम: ₹१०,००० मर्यादा = कमाल ₹३,००० वापर)
- उशिरा पेमेंट (₹१०० उशिरा भरले तरी = CIBIL वर फटका)

#### वय १९: पहिले खरे क्रेडिट कार्ड

**कृती:**
१. **एंट्री-लेव्हल कार्डसाठी अर्ज करा** — ₹१०,०००-₹२५,००० मर्यादा. SBI SimplyCLICK, HDFC MoneyBack, ICICI Platinum.
२. **फक्त ३०% वापरा** — ₹२५,००० मर्यादा = कमाल ₹७,५०० खर्च. १०% वापर = स्कोरसाठी उत्कृष्ट.

**फायदे:**

**सर्वोत्कृष्ट पद्धती:**

### कमी वयात क्रेडिट नष्ट करणाऱ्या सामान्य चुका

१. **एकाच वेळी अनेक कार्ड अर्ज** — १ महिन्यात ५ कार्डे = "क्रेडिटचा भुकेला" असा टॅग. प्रत्येक अर्जामुळे ५-१० पॉइंट घसरतात. अर्जांमध्ये ६ महिने वाट पहा.

२. **क्रेडिट कार्ड मॅक्स आऊट करणे** — ₹१०,००० मर्यादेवर ₹९,००० खर्च = ९०% वापर = स्कोर किलर. ३०% खाली ठेवा, आदर्शपणे १०%.

३. **१ दिवसही उशीरा पेमेंट करणे** — उशिरा पेमेंट शुल्क + व्याज + क्रेडिट स्कोर घसरण. ₹१०० उशिरा पेमेंटमुळे स्कोर ५०+ पॉइंट्सने घसरू शकतो.

४. **जुनी खाती बंद करणे** — जुने कार्ड बंद केले? क्रेडिट इतिहासाचा कालावधी कमी झाला. स्कोर घसरतो. जुनी कार्डे सक्रिय ठेवा, अगदी शून्य वापरासह.

५. **क्रेडिट रिपोर्ट त्रुटींकडे दुर्लक्ष करणे** — चुकीची माहिती ७ वर्षे रिपोर्टवर राहते. नियमितपणे तपासा, त्वरित वाद दाखल करा.

६. **अविश्वासू लोकांसाठी जामीनदार बनणे** — मित्राने थकबाकी केली = तुमचा CIBIL खराब झाला. तुम्ही भरू शकत नसल्यास कधीही जामीनदार बनू नका.

७. **पूर्ण भरण्याऐवजी कर्ज सेटल करणे** — सेटलमेंट रिपोर्टवर "सेटल" म्हणून दिसते (नकारात्मक). शक्य असल्यास पूर्ण रक्कम भरा.

८. **रोख रक्कम काढण्यासाठी क्रेडिट कार्ड वापरणे** — त्वरित व्याज + शुल्क + कोणताही ग्रेस पिरियड नाही = महागडे पैसे + स्कोरवर परिणाम.

९. **कोणतेही क्रेडिट नसणे** — कोणताही क्रेडिट इतिहास नाही = कोणताही स्कोर नाही. लहान कार्डने सुरुवात करा, इतिहास तयार करा.

१०. **तुमच्या नावावरील बिलांकडे दुर्लक्ष करणे** — फोन, वायफाय, वीज — रिपोर्ट केल्यास उशिरा भरल्याने क्रेडिटवर परिणाम होतो.
